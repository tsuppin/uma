# 🐎 Keiba GrandMaster AI (競馬統合マスターGEMシステム)

## 📌 プロジェクト概要
本プロジェクトは、3つの専門的視点を持つAIエージェント（GEM）の分析ロジックを統合し、事実と客観的データのみに基づいた最終的な競馬の買い目と戦略を決定する「データ駆動型・競馬予想システム」です。
感情や主観的なバイアスを完全に排除し、トラックバイアスや期待値を最優先した論理的な予測を行います。

## 🧠 システムアーキテクチャ

本システムは、司令塔となる「統合マスターGEM」と、配下の3つの「専門GEM」で構成されます。

1. **競馬場専門GEM (`agents/track_gem.py`)**
   - 物理的特性、クッション値、トラックバイアスに基づく絶対評価。
2. **陣営分析専門GEM (`agents/camp_gem.py`)**
   - 騎手・調教師のコース実績、ローテーション、斤量恩恵の定量化。
3. **券種別専門GEM (`agents/ticket_gem.py`)**
   - 3連複2頭軸フォーメーション特化。的中率と回収率（期待値）の最適化。
4. **統合マスターGEM (`core/grandmaster_logic.py`)**
   - 各専門GEMの出力を統合。「過剰人気馬のストレステスト」「矛盾発生時のトラックバイアス絶対優先ルール」を適用し、最終結論を算出。

## ⚖️ 基本原則（コア・ルール）
- **ファクトチェック徹底**: JRA公式・客観的統計データのみを使用。
- **感情排除**: 「期待できる」などの主観的ノイズをシャットアウト。
- **物理的制約の最優先**: 陣営評価と馬場バイアスが衝突した場合、例外なく「馬場バイアス」を優先。
